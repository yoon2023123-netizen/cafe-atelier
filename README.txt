CAFE ATELIER — PRO PORTFOLIO DEMO

1. 압축을 푼 뒤 index.html을 더블클릭하면 크롬에서 열립니다.
2. 수정은 메모장으로 index.html / style.css / script.js 파일을 열어 진행할 수 있습니다.
3. index.html은 글과 구성, style.css는 디자인, script.js는 메뉴와 스크롤 애니메이션을 담당합니다.
4. 이미지와 웹폰트는 인터넷 연결이 필요합니다.
5. 주소, 전화번호, 운영시간, 메뉴/가격은 모두 예시입니다. 실제 고객에게 전달하기 전 반드시 실제 정보로 바꾸세요.
6. 이 프로젝트는 가상의 카페 포트폴리오 데모입니다. 실제 매장인 것처럼 게시하지 마세요.
